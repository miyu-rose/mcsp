# mcsp
MACS LOADER/PLAYER for X680x0

・シンプルな MACS ローダ/プレイヤです。

・060turbo.sys / HIMEM.SYS / TS16DRV / TS16DRVp 対応で
　ローカルメモリ / ハイメモリへ適切に配置して再生します。

　[XEiJ + HFS上のファイル]
　[PhantomX + PXVDISK ドライブ上のファイル]
　[Haumea X の Haumea DSK 上のファイル]
　そのまま再生可

　[SCSIドライブ上のファイル]
　たんぼ(TNB製作所) さまの TS16FILE.x 常駐で再生可
　（但しSCSIドライブは読み込み速度的に実用的ではないかも
